# Final Positioning and Compact Landing-Page Architecture

## Narrative hierarchy

**Today**

Project Rankup connects the organic-growth workflow:

`Discover -> Prioritize -> Plan -> Create -> Measure -> Improve`

**Coming Soon**

Agent Mode will increasingly automate that workflow.

**Vision**

Organic Growth on Autopilot.

Agent Mode is not implemented. The landing page must not invent its jobs, schedules, triggers, permissions, approval systems, or interface.

## Approved hero

**Eyebrow:** The organic-growth platform

**Headline:** Turn visibility into growth.

**Subheadline:**

**Primary CTA:** Start free

**Secondary CTA:** See how it works

The hero sells the outcome: visibility becomes growth. The Growth Loop directly underneath explains the mechanism. “Visibility” intentionally leaves room for traditional search, AI search, GEO/AEO, citations, recommendations, and future discovery surfaces without claiming that every surface is supported today.

## Recommended compact page architecture

### 1. Hero + immediate proof

Use the approved hero verbatim, **Start free**, **See how it works**, The Growth Loop visual, and the two supplied customer testimonials as early proof.

### 2. The problem becomes the workflow

Show how disconnected research, calendars, generators, and analytics lose context, then resolve that fragmentation with the six-stage loop.

### 3. Interactive product story

Use one large Linear-influenced composition to follow the same opportunity through Discover, Prioritize, Plan, and Create. Preserve the opportunity and project context across every state.

### 4. Measure -> Improve

Complete the loop with performance evidence, an audit or refresh opportunity, and the next improvement. Current functionality remains user-directed.

### 5. Agent Mode — Coming Soon

Treat this as a visually significant horizon, not a shipped product demonstration. Show the established Growth Loop becoming more continuous or self-propelling, then resolve into the explicit label **Agent Mode — Coming Soon** and the single statement: “Agent Mode will increasingly automate the organic-growth workflow.”

Do not show speculative controls, tasks, schedules, approval systems, or completed agent actions. A possible treatment is a continuation of the same loop composition: current stages are solid and interactive; the future automation path appears as a precise line, pulse, or progressive connection extending through them. The distinction should be exciting and unmistakable.

### 6. Evidence + why it works

Combine the exact Taggd and JaipurStuffs testimonials with persistent project context, inspectable research, and the confirmed plan depth. Pricing can appear here or on a dedicated route.

### 7. FAQ + final CTA

Answer CMS publishing, Agent Mode’s Coming Soon status, supported data sources, credits, content formats, and audience. Close with **Start free**.

- Outcome first; the product visual explains the system.
- Current workflow in present tense.
- Agent Mode only in future tense and always paired with **Coming Soon**.
